## What is this?
 
**sorry-letter** is a heartfelt, animated React web experience built for one purpose: delivering an apology that actually *feels* like one.
 
When you open the page, you're greeted with a sealed envelope sitting quietly on screen. Clicking it triggers a cascade of animations — the envelope unfolds, a handwritten letter rises out, and the song **Bairan** starts playing softly in the background, setting the mood before a single word is read.
 
The letter says what needs to be said. And at the end — a single button that redirects straight to WhatsApp with the message pre-filled:
 
> *"I forgive you"*
 
Because making it easy to forgive is the whole point.
 
---

## ✨ Features
 
- 🎭 **Envelope open animation** — smooth, multi-step CSS animation of an envelope unfolding
- 💌 **Letter reveal** — the letter rises out of the envelope with a cinematic entrance
- 🎵 **Auto-play music** — *Bairan* begins playing the moment the envelope opens
- 📱 **WhatsApp redirect** — a button at the end of the letter opens WhatsApp with `"I forgive you"` pre-filled as the message
- 📱 **Fully responsive** — works on mobile and desktop
- 🎨 **Rich animations** — particle effects, floating hearts, ink-fade text reveals, and more

## 🚀 Getting Started
 
### Prerequisites
 
- Node.js `v18+`
- npm or yarn
 
### Installation
 
```bash
git clone https://github.com/devks19/sorry-letter.git
cd sorry-letter
npm install
```
 
### Development
 
```bash
npm run dev
```
 
### Build for Production
 
```bash
npm run build
```
